# 蓝鱼枪战 · 深海火拼（Deep Sea Gunfight）

一个纯前端的深海射击小游戏：你是**蓝鱼**，深海里的**红鱼**拿着枪围猎你。

## 运行方式

**在线玩**：部署在 GitHub Pages 上，手机 / 平板 / 电脑打开网址即可，无需安装。

**本地玩**：双击打开 `index.html` 即可（Chrome / Edge / Safari 都行）。
整个文件夹要一起保留（`index.html` 依赖同级的 `assets/`）：

```
/
├── index.html          页面结构（开始 / 暂停 / 设置 / 升级卡片 / 档案 / 商店）
├── style.css           界面样式（发丝边框、分层遮罩、入场动效）
├── audio.js            音频引擎（合成音效 + 背景音乐，无音频素材文件）
├── game.js             全部游戏逻辑 + Canvas 渲染
├── README.md
└── assets/
    ├── fonts/          Inter（拉丁与数字，可变字重）/ 思源黑体子集（中文，400/600/700）
    ├── img/            Blender 渲染的主视觉 + 程序化生成的水下光斑、辉光、火花、颗粒、气泡
    └── README.md       素材来源与许可
```

> 素材全部本地化：字体已下载为 woff2，贴图用 numpy + Pillow 程序化生成，
> 主视觉那条鱼是 Blender + Cycles 真建模渲染出来的。断网也能玩。
> 生成脚本不在本站点里，见 `assets/README.md` 的复现说明。

## 操作

| 按键 | 作用 |
| --- | --- |
| `W A S D` / 方向键 | 游动（水下有惯性，松手会滑行） |
| 鼠标 | 瞄准（枪口跟随鼠标，身体跟随游动方向） |

| `P` / `Esc` | 暂停 / 继续（暂停页可进设置） |
| `R` | 重新开始 |
| `M` | 静音开关 |

### 手机 / 平板

手机上会自动切换成触屏操作（含横屏提示与更紧凑的 HUD）：

| 手势 | 作用 |
| --- | --- |
| 左半屏按住拖动 | 虚拟摇杆游动（推多远走多快） |
| 右半屏按住 | 点哪打哪，按住持续开火 |
| 右下 `⚡ 冲刺` | 冲刺（2 秒冷却） |
| 右下 `◎ 深海脉冲` | 以自身为中心 250 px 清场（18 秒冷却） |
| 摇一摇手机 | 同样释放深海脉冲 |
| 左下 `Ⅱ` | 暂停 |
| 底部枪械条 | 点按换枪 |
| 左半屏快速双击 | 冲刺（不用去够右下角的按钮） |
| 设置 → 左手模式 | 左右操作区对调（摇杆在右、开火在左） |

竖屏时会提示「请横屏游玩」；iPad 等大屏在竖屏下也能正常游玩。
渲染分辨率会随帧率自动调节（掉帧时先降分辨率，不会卡顿）。

### 只有手机才有的东西

这些是刻意做成「触屏独占」的，桌面上不会出现（甚至画都不画）：

- **震动反馈** —— 开火轻点、击杀短震、Boss 倒地重震、受伤重震、冲刺中震。
  在 App 里走 `UIImpactFeedbackGenerator`（通过 `WKScriptMessageHandler` 桥接），
  浏览器里退回 `navigator.vibrate`。可在设置里关掉。
- **体感微调** —— 打开后以你打开开关时的姿态为基准，前倾低头会让准星轻微前后偏移，
  相当于用「身体」做微瞄准（±26° 满量程，位移最多 58 px）。没有陀螺仪的设备会提示不可用。
- **深海脉冲** —— 一个只给触屏的保命技能：点按钮或摇一摇手机，
  250 px 内所有鱼受 6 点伤害（Boss 8 点）并被击退，同时震屏 + 重震动。18 秒冷却。
- **触屏辅助瞄准** —— 按住开火时，470 px 内 ±15° 的最近敌人会把枪口轻轻吸过去
  （每帧 55% 靠近，不会硬锁）。可在设置里关掉。
- **屏幕常亮** —— 进游戏时申请 `Wake Lock`，手机上不会因为发呆就锁屏；切回前台自动重取。
- **横屏告知 + 安全区适配** —— 竖屏显示旋转提示；刘海/灵动岛区域用 `env(safe-area-inset-*)` 让开。

## 打包成 iOS App

`app/` 下是 iOS 壳（Swift + WKWebView），把网页整包塞进 App，横屏全屏、禁滚动回弹、

```

app/ios/App/AppDelegate.swift       @main，强制横屏，isIdleTimerDisabled
app/ios/App/ViewController.swift    全屏 WKWebView + haptic 消息桥
app/ios/Support/Info.plist          显示名「蓝鱼枪战」、仅横屏、隐藏状态栏
app/build-ipa.sh                    拷网页资源 → xcodegen → xcodebuild → zip 成 ipa
app/make-icon.py                    用 3D 主视觉合成 1024 图标
.github/workflows/build-ipa.yml     macOS runner 上自动构建，产物回到 dist/
```

本机没有 Xcode，所以构建是在 GitHub Actions 的 macOS runner 上做的。

包内已含液态玻璃 UI、自绘图标、启动动画、七把武器图标与手柄支持。

## 规则

- 打 **3 枪**干掉一条红鱼（手枪 1 点伤害 × 红鱼 3 点血）。
- 红鱼打你 **20 枪**你就被击倒，**2.6 秒后原地满血复活**（武器与强化卡保留）。
- 每击杀 **20 条**红鱼升一级，从 **3 张强化卡**里选 1 张。

## 波次 · 金币 · 商店

- 红鱼分 **波次**来袭，每波敌人数量递增，种类随波次解锁（冲锋兵 / 重甲兵 / 狙击兵）。
- **清空一波** → 进入 **整备阶段**（12 秒）：没有敌人，可以买补给、回血、捡漏；
  按下"提前出击"还能拿 **+3 金币** 的抢时间奖励。
- 击杀红鱼会掉 **金币**，波次通关也有金币奖励。整备期商店每次随机刷 **3 件商品**：
  应急修理 / 护盾电池 / 强化鱼鳔 / 强化卡包 / 黑市军火（随机解锁一把枪）/
  狂暴药剂（45 秒伤害 +60%）/ 磁力脉冲 / 水流加速 / 瞄准芯片。
- 每 **5 波** 是 **Boss 波**，四只 Boss 轮番上阵，每轮之后血量再涨一档：

| Boss | 打法 |
| --- | --- |
| 深海鲨王 | 五连榴弹扇形覆盖；会召唤小兵，抓到破绽再输出 |
| 灯笼鮟鱇 | 吐追踪光球；张嘴突进时最脆，诱饵灯是它的破绽提示 |
| 雷纹海鳗 | 蓄力后一枪致命的电击（有红色预警线）；贴身会被环形放电 |
| 爆刺河豚 | 膨胀时受伤减半、同时打出 12 发环射；别在它膨胀时硬顶 |

## 画面

- **水下光照**：两条互相交叉的焦散图层（相位差 0.5s）做加色叠加，配合 6 道体积光束、
  水面光池和随深度衰减的雾，营造"越往下越暗"的纵深感。
- **图层分级**：沙地 / 岩石 / 珊瑚预渲染成一张静态层并做降饱和 + 底部压暗，
  前景海草在角色之上再画一遍，形成"礁石退后、鱼群在前"的三段景深。
- **鱼是画出来的**：战斗里的主角和红鱼都是 Canvas 路径逐帧绘制（渐变身体、半透明鱼鳍、
  瞳孔跟随准星、受击白闪、冲刺残影），没有贴图，缩放不会糊；Boss 各有独立造型
  （鮟鱇的獠牙巨口与诱饵灯、海鳗的电弧、河豚的尖刺与膨胀）。
  开始界面那条蓝色主视觉是 Blender 建的模、Cycles 渲的 2048² 透明 PNG。
- **特效**：子弹双层拖尾 + 辉光核心、命中火花、暴击数字、击杀爆散、
  低血量红边脉冲、动态胶片颗粒、准星命中锁定括弧。
- **动效**：界面切场用透明度 + 位移（不是模糊），HUD 数值滚动，成就与波次提示弹出。

## 界面：液态玻璃

- **玻璃三层**：`backdrop-filter: blur() saturate()` 的毛玻璃底 + 顶部 1px 内高光 + 外投影，
  浮起的东西（面板、Dock、弹层）才用玻璃，贴在画面里的元素保持平涂，避免"什么都糊一层"。
- **高光跟随指针**：按下时把指针位置写进 `--px/--py`，玻璃上的扫光斑会跟着走；
  手机上接陀螺仪，轻微转动会让高光群整体偏移（`--tilt-x/--tilt-y`）。
- **动态明暗**：`--amb` 随战况变——菜单最亮、Boss 出场压暗、残血再压一档，
  玻璃的透光量跟着走，不是死板的固定值。
- **四档画质**：`流畅 / 标准 / 高 / 极致`，分别控制 `blur` 半径、`saturate`、
  焦散与光束数量、颗粒强度、DPR 上限（0.9×–2.2×）。默认「高」，掉帧会自动降一档并提示。
- **启动动画**：Tian Studio 的标志（圆环 + 水面 + 声呐涟漪）逐笔描出、扫光掠过、
  字标逐字揭示，落款 **TIAN GAMES ENGINE v1.0** 从底部浮起；点击/按键可跳过，
  `?noboot=1` 直接进（详见 `boot.js` / `boot.css`）。

## 界面与字体

- 字体全部内置在 `assets/fonts/`，离线双击 `index.html` 也能正确显示：
  - **Inter**（`inter-var.woff2`，可变字重 100–900）负责拉丁字母和所有数字，开启 `tnum` 等宽数字，
    血量、连杀、金币跳动时不会左右抖。
  - **思源黑体 Noto Sans SC** 子集（`noto-sans-sc-400/600/700.woff2`）负责中文，按游戏里实际出现的
    1206 个字符裁过，三档合计约 460KB；缺字自动回落到系统 PingFang / 雅黑。
  - 中文和拉丁用同一套字号/行高节奏，画布里的文字也读同一组 `UI_FONT` / `DISP_FONT`，
    不会出现「HUD 是一种字、连杀数字又是另一种字」。
- 排版：标题负字距（-.04em）压紧，正文行高 1.6；最小字号 9px 只用于次要标签，
  移动端矮屏会整体收一档。

## 手感（打击反馈）

打出去要有回应，这是这一版重做交互的重点：

- **顿帧**：命中 0.014s、暴击 0.035s、击杀 0.052s（8 连以上 0.075s）、
  被击中 0.07s、Boss 出场 0.20s —— 顿帧期间时间流速降到 6%，
  打击感来自"世界停一下"而不是血量数字。
- **连杀**：击杀累加连杀计数，2.4s 内不再击杀就断（挨打立刻断），
  屏幕右侧有计时环 + ×N 计数，5 / 15 连换色，每 5 连飘一次「连杀！」。
- **准星回馈**：命中在准星上炸出四段括弧（击杀转金色并加环），
  开枪时准星会因后坐向外弹一下。
- **屏幕上的物理**：击杀冲击波、点击/冲刺的水面涟漪、冲刺残影、受击挤压回弹、
  击退抖动、镜头震动（轻重随连杀与是否 Boss 递增）。
- **数字**：HUD 的击杀/得分/金币是滚动跳字（不是瞬间替换），
  刷新时会有一次轻微弹跳。
- **界面**：所有按钮有抬升、按压形变和扫光；卡片可以 3D 倾斜并跟随指针有高光，
  选中卡有金环 + 同排其余变暗；商店买得起/买不起的价格条会呼吸或抖动；
  切场是透明度 + 位移的错峰进场，不留模糊。
- **可访问性**：`prefers-reduced-motion` 下关闭位移动画与心跳脉冲。

## 声音

全部由 WebAudio 实时合成，没有任何音频素材文件（`audio.js`，约 1450 行）：

- **混音链**：master → 低架 +1.4dB@92Hz / 高架 −1.6dB@7.2k → 限幅器（−3.5dB, 16:1）
  → tanh 安全削波器（硬保证 |out| ≤ 0.97）→ 输出。四条独立总线（音效 / 音乐 / 环境 / 混响）。
- **混响**：ConvolverNode + 程序生成的 2.7 秒脉冲响应（噪声 × 指数衰减 × 时变低通，
  带早期反射），不是简单的延迟反馈。
- **音效**：27 个 cue 每个 3~5 层（瞬态 / 主体 / 噪声尾 / 低频冲击 / 空气感）。
  7 把枪靠质心频率、尾巴长度、频段分布硬区分：手枪干短、冲锋枪极短且高瘦、
  霰弹宽噪声带大低频、狙击有裂空瞬态和两声错位的回声尾、榴弹是低频闷响加推进 whoosh、
  三叉戟是三连上行的 D5-G5-C6、激光是起振扫频 + 持续音。
  每次触发还有 ±16 音分抖动，连发不会变成机械的哒哒哒。
- **空间**：`playAt` 按距离做低通 + 声像 + 音量衰减，远处的枪声更闷、混响送得更多。
- **音乐**：92 BPM，D 小调，16 小节循环 ——
  `|Dm|Bb|F|C|Dm|Bb|C|C| / |Gm|Bb|F|C|Dm|Bb|A7|A7|`，
  失谐双振荡器的 pad + 会加五度/八度的贝斯 + 手工谱写的 44 音旋律 + 琶音 + 合成鼓组，
  A 段稀疏、B 段铺满，收在 C#→D 的导音解决上。
- **动态**：`setIntensity` 真正驱动分层（残血、敌人多时加 hat、加 kick、加失真、开 EQ），
  并且和音效做 sidechain —— 你连射的时候音乐自动让位。
- **环境音**：水下的低频噪音床，配合偶发的远处鲸歌（FM 啸叫 + 颤音）。

## 设置

音效音量、背景音乐、屏幕震动、粒子效果（低/中/高）、难度（轻松/普通/狂暴）、
伤害数字开关、清空最高分 —— 全部自动保存在浏览器 localStorage 里。

触屏设备上还会多出一组「03 触屏 / MOBILE」：震动反馈、体感微调、摇一摇脉冲、
触屏辅助瞄准（桌面端这一组不显示）。
难度也可以在开始界面直接切换。

## 想改数值？
